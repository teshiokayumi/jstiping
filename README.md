# JS用語タイピングゲーム

JavaScriptのプログラミング用語（予約語、メソッド、オブジェクトなど）を楽しく覚えられるタイピングゲームです。
入力練習だけでなく、音声読み上げ機能による発音確認や、終了後の単語リストによる意味の復習も可能です。

## 特徴

- **JS用語特化**: `function`, `addEventListener`, `console.log` など、実務で頻出する用語が出題されます。
- **音声読み上げ**: 単語を入力し終えると、ブラウザの音声合成機能（Web Speech API）を使って英語の発音を読み上げます。
- **復習機能**: ゲーム終了後に、そのプレイで出題された単語と日本語の意味が一覧表示されます。
- **スタイリッシュなUI**: ダークモードを基調とした、集中しやすいネオン風のデザインです。

## 遊び方

1. `index.html` をブラウザで開きます。
2. 画面に表示されるアルファベットをタイピングします。
3. 全20問正解するとゲームクリアです。完了までのタイムが表示されます。
4. 終了後、画面下部に単語リストが表示されるので、分からない単語の意味を確認できます。

## 動作環境

- Google Chrome, Edge, Firefox, Safariなどの最新モダンブラウザ
- インターネット接続は不要（オフラインで動作します）

## 技術スタック

- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (ES6+)
  - **SpeechSynthesis API**: テキスト読み上げに使用
